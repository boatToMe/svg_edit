# SVG 可视化编辑器

一个用 Python 标准库实现的 SVG 可视化几何编辑工具，适合快速查看和拖拽修改常见 SVG 图元。

## 功能

- 打开本地 `.svg` 文件
- 枚举并选择文件中的可编辑图元
- 当前支持 `path`、`line`、`polygon`
- 画布会同时显示全部可编辑元素，当前选中元素会高亮
- 元素列表使用 `元素1`、`元素2` 这样的名称
- 切换选中元素时，画布左上角会短暂提示当前选中项
- 显示 `viewBox` 边界和中心十字辅助线，方便排版对齐
- 当前元素超出 `viewBox` 时，`viewBox` 参考线会变成警示色
- 画布底部会显示 `viewBox` 尺寸和是否超出范围的提示
- 辅助线面板包含辅助线列表，可选中、删除、清空辅助线
- 在辅助线列表中选中某条辅助线后，可在画布中直接拖动它
- 可手动添加 `x/y` 辅助线，也可从当前焦点点一键生成辅助线
- 节点旁显示坐标数字，当前焦点点的数字会高亮
- 拖动端点时，几何数据区中对应数字会高亮
- 选中几何数据区中的数字时，对应端点会高亮
- 可对选中的同值数字执行批量修改
- 端点、图形整体和辅助线拖动都支持按步长吸附
- 拖动节点、图形或辅助线后可使用 `Ctrl + Z` 撤销，`Ctrl + Y` 重做
- 在右侧文本框中手工编辑几何数据，再回应用到画布
- 主窗口左侧内嵌浏览器内核预览面板，按浏览器标准渲染 SVG
- 预览面板可设置整个图形或指定元素的预览属性
- 预览目标下拉框会显示更清楚的元素标签，例如 `元素1 · path`
- 在预览面板选中某个元素目标时，对应元素会以橙色短暂闪烁提示
- 支持设置线条宽度、线条颜色、填充颜色、圆角近似效果、`stroke-linecap`、`stroke-linejoin`
- 预览画布背景可在亮色和暗色之间切换
- 保存或另存为前可预览最终生成的 SVG 代码
- 保存 SVG 时，会把可编辑元素的填充色规范为 `var(--background)`，线条色规范为 `currentColor`，方便外部 CSS 控制
- `Ctrl + 0` 可快速打开 SVG 文件
- 保存为原文件或另存为新文件

## 运行

```powershell
python app.py
```

## 交互

- 左键拖拽节点：移动当前选中元素的节点
- 左键拖拽当前选中图形本体：整体移动当前图形
- 按住空格并左键拖拽：移动画布
- 在辅助线列表中选中辅助线后，左键拖拽画布中的该辅助线：移动辅助线
- 在编辑设置中输入拖动步长：限制端点、图形整体和辅助线每次拖动的变化步长
- 在几何数据区选中数字：高亮对应端点
- 点击“批量修改同值”：把当前选中的那个数值在文本中做全局同值替换
- 点击“刷新预览”：重新生成左侧内嵌浏览器预览
- `Ctrl + 0`：打开 SVG 文件
- 在预览面板中可按“整体图形”或具体元素标签设置样式
- 在预览面板中可设置线条宽度、线条颜色、填充颜色、圆角、边界处理、拐弯处理
- 在预览面板中可切换“亮色 / 暗色”背景主题
- 在预览面板中输入目标宽度（px）后点击“应用尺寸”：按像素宽度缩放预览
- 在预览面板中点击“放大 10% / 缩小 10%”：调整预览尺寸
- 点击“保存”或“另存为”前，会先弹出 SVG 代码预览确认窗口
- `Ctrl + Z`：撤销
- `Ctrl + Y`：重做
- 鼠标滚轮：缩放主画布

## 右侧文本格式

- `path`: 编辑 `d`
- `line`: 按 `x1 y1 x2 y2` 编辑
- `polygon`: 编辑 `points`

## 当前支持的 path 指令

- `M/m`
- `L/l`
- `H/h`
- `V/v`
- `C/c`
- `S/s`
- `Q/q`
- `T/t`
- `Z/z`

说明：工具会在内部把部分简写指令展开后再保存，所以保存后的 `d` 文本可能和原始写法不同，但几何形状会保持一致。左侧预览现在直接使用内嵌浏览器内核进行标准 SVG 渲染，不再依赖外部浏览器。
